TerrainForge 3D

Algorithm Analysis & Comparison

View & Layout

View Mode

Switches the layout between a 5-way comparative grid and a single focused algorithm.

Grid View: View all algorithms side-by-side.

Focused View: Isolates one algorithm in full detail.

Auto-Rotate Speed

The speed at which the camera automatically orbits around the center of the terrain.

Controls: Orbit rotation velocity in degrees per frame.

Effect: Higher values rotate faster; 0 pauses rotation.

Noise Speed

Controls how fast the terrain noise pattern scrolls across the surface.

Controls: Noise offset velocity multiplier.

Effect: Higher values make the terrain flow faster; 0 freezes the terrain in place.

UI Scale

Resizes the text, inputs, and layout dimensions of the control panel and overlays.

Scale Range: 80% (compact) to 150% (enlarged).

Significance: Crucial for high-resolution displays and general visual accessibility.

Show Wireframe
Wireframe Overlay

Overlays the wireframe structure of the terrain grid.

Significance: Displays the underlying triangulated geometry of the mesh, useful for visual analysis of terrain density and slope complexity.

Show Metrics Overlay
Metrics Overlay

Toggles the FPS, Frame time, Render performance, and Mathematical analysis overlays over the 3D canvas.

Significance: Hiding metrics provides an unobstructed 100% full-screen view of the 3D terrain canvas.

Hotkey: Press M to toggle.

Terrain Configuration

Terrain Seed

The starting seed value for the pseudo-random number generator (PRNG).

Significance: Using the same seed guarantees identical terrain generation. Changing it generates new landforms.

Tessellation

The vertex density of the terrain mesh, representing the number of subdivisions in the 3D plane.

Calculated: N x N divisions (e.g., 40x40 to 320x320 grid segments).

Significance: Higher values create more detailed and visually complex terrain but increase rendering computations.

Camera Zoom

The distance of the camera from the center of the 3D grid.

Significance: Lower values zoom in close for structural details; higher values zoom out for a bird's-eye view.

Camera Pitch

The vertical polar angle of the camera relative to the terrain plane.

Significance: Adjusts viewpoint from side-on profile (low pitch) to top-down orthographic (high pitch).

Target Offset X

The horizontal X translation of the camera focus target.

Target Offset Y

The vertical Y translation of the camera focus target.

Target Offset Z

The horizontal Z translation of the camera focus target.

Height Scale

The maximum vertical displacement (amplitude) of the terrain vertices.

Significance: Stretching this value increases steepness, making mountain peaks taller and valleys deeper.

Width Scale

The horizontal stretch (X and Z boundaries) of the terrain mesh.

Significance: Stretching this value expands the horizontal dimensions of the landform, making features wider.

Noise Scale

The horizontal scale or zoom level of the generator's noise patterns.

Significance: Lower scale values pack features tightly for chaotic details; higher values create broad, smooth plains.

Noise Octaves

The number of detail layers layered together to construct the fractal noise terrain.

Significance: Each additional octave adds finer micro-features. More octaves create much more organic landforms.

Persistence

Controls the amplitude decay (visual strength) of each successive noise octave.

Significance: High persistence gives fine details more power, resulting in a rougher, more jagged terrain.

Color Palette

The color scheme applied to vertex elevations.

Natural: Water, sand, grass, rock, and snow transitions.

Thermal/Oceanic/Metallic: Styling overrides for analytical views.

Physical Simulation (Erosion)

Hydraulic Erosion

Simulates physical rainfall weathering the terrain over time.

Controls: Click to play/resume or pause the simulation. Pausing keeps the current eroded state visible.

Significance: Rain droplets flow downhill, eroding high peaks and depositing soil sediment in low valleys.

Performance & Limits

Frame Rate Cap

Limits the refresh rate of the animation loop to save system resources.

Significance: Capping frame rates helps reduce CPU/GPU temperatures and power draw, especially on laptops.

Custom FPS Cap

Enter a custom numerical refresh rate limit between 15 and 240 FPS.

Keyboard Shortcuts

  • 1 - 5 : Focus Algorithm
  • 0 or ` : Comparative View
  • B : Toggle Benchmark

Value Noise (c. 1980)

Lattice
FPS -- /--
FPS (Frames Per Second)

The frequency at which the simulator renders consecutive images (frames) to the screen.

Calculated: 1000ms divided by the average frame time.

Represents: Overall visual fluidity and update frequency.

Significance: Crucial for measuring interface responsiveness and smooth animation.

Frame --ms /--ms
Frame Time

The total time elapsed between two consecutive frame updates, representing the complete frame cycle.

Calculated: Time delta between successive frames using performance.now().

Represents: Total CPU/GPU time budget consumed per frame cycle.

Significance: Must stay below 16.7ms for 60 FPS, or 8.3ms for 120 FPS, to prevent stutter.

Render --ms /--ms
Render Time

The time spent preparing and drawing the 3D scene using WebGL/Three.js.

Calculated: Elapsed time of the scene draw and GPU submission sequence.

Represents: Graphics pipeline workload and CPU-to-GPU command overhead.

Significance: Identifies draw call bottlenecks, mesh complexity limits, or shader performance issues.

Math --ms /--ms
Math Time

The time taken by the noise generator or subdivision algorithm to calculate height values.

Calculated: Execution timing of the height grid calculation block (including erosion steps).

Represents: Core algorithmic complexity and CPU computation cost.

Significance: Direct indicator of algorithm efficiency. Lower math times allow higher grid resolutions without freezing.

Rugged -- /--
Ruggedness

The relative physical roughness, slope steepness, or complexity of the terrain surface.

Calculated: Root-mean-square (RMS) of elevation changes between adjacent grid vertices.

Represents: Geometric noise intensity and fractal dispersion features.

Significance: Quantifies the aesthetic variation and geologic realism generated by each algorithm.

Mathematical Analysis

Assigns random values to grid intersections and interpolates between them. Produces blockier, more angular grid-aligned shapes.

Time (Vertex): Θ(1)
Time (Grid): Θ(N²)
Space (Aux): Θ(1)
Space (Grid): Θ(N²)
